# The W3C stack

<div class="stack">
  <div><b>Query</b><span>SPARQL: ask questions, across graphs</span></div>
  <div><b>Validate</b><span>SHACL: check data against rules</span></div>
  <div><b>Describe</b><span>RDFS, OWL, SKOS: classes, hierarchies, vocabularies</span></div>
  <div><b>Write</b><span>Turtle, JSON-LD, RDF/XML: file formats for triples</span></div>
  <div class="stack-core"><b>Model</b><span>RDF: everything is a triple</span></div>
</div>

<div class="sdsc-takeaway">Only RDF is required. Add the other layers when you need them.</div>

<p class="fine">Status, November 2026: RDF 1.2 and SPARQL 1.2 are W3C Candidate Recommendations; SHACL 1.2 is a Working Draft.</p>
