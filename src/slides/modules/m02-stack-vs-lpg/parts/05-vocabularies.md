# Languages and vocabularies

::left::

## Modelling languages

Used to write vocabularies:

- **RDFS**: classes, subclasses, domain and range
- **OWL**: richer logic for reasoning
- **SKOS**: thesauri, code lists, taxonomies
- **SHACL**: rules your data must follow
- **XSD**: datatypes for values

::right::

## Domain vocabularies

Reuse them for your data:

- **schema.org**: things on the web, recipes included
- **Dublin Core**, **DCAT**: documents and datasets
- **PROV-O**: who made what, how
- **QUDT**: units and quantities
- **Wikidata**: identifiers for almost anything

::bottom::
