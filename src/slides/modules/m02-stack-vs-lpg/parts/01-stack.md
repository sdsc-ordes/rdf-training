# The W3C stack

<div class="stack">
  <div><b>Query</b><span>SPARQL: ask questions, across graphs</span></div>
  <div><b>Validate</b><span>SHACL: check data, infer triples with rules</span></div>
  <div><b>Describe</b><span>RDFS, OWL, SKOS: classes, hierarchies, vocabularies</span></div>
  <div><b>Write</b><span>Turtle, JSON-LD, RDF/XML: file formats for triples</span></div>
  <div class="stack-core"><b>Model</b><span>RDF: everything is a triple</span></div>
</div>

<p class="fine">Status, November 2026: RDF 1.2 is a W3C Candidate Recommendation; SPARQL 1.2 and SHACL 1.2 are Working Drafts.</p>

<p class="fine">Sources: W3C TR</p>
