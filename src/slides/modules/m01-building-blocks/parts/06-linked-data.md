# Linked Data: four rules

1. Use IRIs as names for things
2. Use HTTP(S) IRIs, so people can look them up
3. When someone looks one up, return useful data in a standard format
4. Link to other IRIs, so they can discover more

<div class="sdsc-takeaway">Try it: open <a href="https://www.wikidata.org/entity/Q29">wikidata.org/entity/Q29</a>, the IRI for Spain.</div>

<p class="fine">Sources: Berners-Lee 2006</p>
