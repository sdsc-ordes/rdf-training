# Tools for modelling

<table class="compact tight">
  <thead><tr><th>Tool</th><th>For</th></tr></thead>
  <tbody>
    <tr><td>Protégé, WebProtégé</td><td>Ontology editor with reasoners; WebProtégé runs in the browser, for teams</td></tr>
    <tr><td>VocBench 3</td><td>Web editor for OWL ontologies and SKOS thesauri, used for EuroVoc and AGROVOC</td></tr>
    <tr><td>VS Code + RDF extensions</td><td>Writing Turtle and SPARQL with highlighting and checks</td></tr>
    <tr><td>Chowlk</td><td>Draw the model in diagrams.net, convert it to OWL</td></tr>
    <tr><td>LinkML</td><td>Model in YAML, generate RDF, SHACL, JSON Schema and Python</td></tr>
    <tr><td>SHACL Play!</td><td>Write shapes in a spreadsheet, document and draw them (more in module 4)</td></tr>
    <tr><td>WebVOWL</td><td>Seeing an ontology as a diagram</td></tr>
    <tr><td>pyLODE, Widoco</td><td>Publishing documentation pages for a vocabulary</td></tr>
    <tr><td>TopBraid EDG, metaphactory, PoolParty</td><td>Commercial platforms for teams</td></tr>
    <tr><td>Any LLM</td><td>A first draft, which you then check (module 5)</td></tr>
  </tbody>
</table>
